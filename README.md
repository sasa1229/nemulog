# ねむログ — 夜の帳簿

必要睡眠時間と睡眠負債を、シフト生活のまま管理する睡眠記録PWAです。

## 使い方

ブラウザで公開URLを開くだけで利用できます。ホーム画面に追加するとアプリのように起動できます（PWA対応・オフライン利用可）。

## 公開URL

https://kyoumonemui.github.io/nemulog/

## 構成ファイル

- `index.html` — アプリ本体
- `manifest.webmanifest` — PWAマニフェスト
- `sw.js` — Service Worker（オフラインキャッシュ）
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — アイコン
